Présentation du projet
Contexte, objectifs et acteurs
🏭 Qu'est-ce que SENTINEL ?

SENTINEL est un système de surveillance environnementale pour zones logistiques portuaires. Il détecte automatiquement des anomalies dans les capteurs IoT installés dans des entrepôts (gaz, température, humidité) et alerte en temps réel.

Inspiré du Port de Rotterdam, le projet répond à une question réelle : comment détecter une fuite de gaz, un incendie, ou une intrusion avant qu'il ne soit trop tard ?

💡 Pour un enfant : Imagine des entrepôts au port avec des capteurs qui sentent l'air. Si l'air sent mauvais (gaz, fumée, chaleur anormale), SENTINEL allume une alarme et dit exactement quel entrepôt est en danger.

🌲 Algorithme de détection : Isolation Forest

Pourquoi Isolation Forest ?

AlgorithmeSupervisé ?Données labellisées ?Choix
Isolation ForestNonNon requisesRetenu
Autoencoder (DL)NonNon requisesTrop complexe
LOFNonNon requisesLent sur 400k lignes
SVM (One-class)NonNon requisesPas adapté aux TS
Random Forest classiqueOuiRequisesPas de labels
✅ Isolation Forest est non-supervisé : pas besoin de données étiquetées "normal/anomalie". Il apprend lui-même ce qu'est une mesure normale.

Comment ça marche ?

Isolation Forest construit des arbres aléatoires. Une anomalie est facile à isoler (peu de coupures nécessaires) → score négatif fort. Une mesure normale est difficile à isoler (beaucoup de coupures) → score proche de 0 ou positif.

contamination0.1 (10% d'anomalies attendues)
random_state42
Featuresco, lpg, smoke, temp, humidity

Problème critique #2 — Multiplication des serveurs Flask
Chaque fois que Flask était relancé depuis VS Code, l'ancien processus restait actif. Au bout de quelques lancements, 5+ serveurs tournaient sur le port 5000 simultanément. Certains répondaient encore avec l'ancienne API SQLite.
✅ Solution : Get-Process python | Stop-Process -Force dans PowerShell pour tuer tous les processus Python, puis relancer uniquement python app.py. Pour éviter que ça se reproduise : ne jamais fermer le terminal VS Code sans arrêter le serveur d'abord (Ctrl+C).
🗄️
Problème critique #5 — Données Flux invisibles dans SQL
InfluxDB Cloud utilise deux moteurs de stockage différents. Les données écrites via l'API Flux (ce que fait SENTINEL) vont dans TSM. Le Data Explorer en mode SQL utilise IOx — un moteur différent qui ne voit pas les données TSM. Résultat : la table simulations semblait ne pas exister.
✅ Solution : utiliser l'onglet "Script Editor (Flux)" dans le Data Explorer. Les données sont bien là. Vérification faite : 9 953 lignes dans sensor_events, 57 213 dans critical_alerts.
🏭
Problème critique #6 — Simulation multi-entrepôt
La simulation n'avait qu'un seul état global : simRunning, simIdx, simBuffer. Impossible de faire tourner A et B simultanément. Cliquer sur B pendant que A tournait soit cassait A, soit était ignoré.
✅ Solution : refactorisation complète avec un objet simStates = {A:{...}, B:{...}, C:{...}}. Chaque entrepôt a son propre timer setInterval indépendant. La fonction toggleSimWH(id) démarre le loop d'un nouvel entrepôt en cours de simulation.

Perspectives d'amélioration
Ce qui pourrait être ajouté ou amélioré
🚀 Améliorations prioritaires
Priorité haute
🔐 Authentification réelle
Actuellement le RBAC est côté client (JavaScript). N'importe qui peut inspecter le code et accéder à l'admin. Solution : implémenter Flask-Login avec bcrypt (déjà installé) et sessions serveur.
Priorité haute
📡 Capteurs ESP32 réels
Le projet utilise un dataset replay. Pour une vraie installation, des capteurs ESP32 enverraient des données en temps réel via MQTT → Telegraf → InfluxDB. L'architecture Flask est déjà prête pour ça.
Priorité moyenne
📤 Export CSV des données
Ajouter un bouton "Exporter" dans les onglets Logs et Alertes pour télécharger les données filtrées en CSV. Simple à implémenter côté JS avec Blob + URL.createObjectURL.
Priorité moyenne
🔔 Notifications push
Alertes en temps réel via WebSockets ou Server-Sent Events. Quand un score CRITIQUE est détecté, notification immédiate sans attendre le refresh de 30 secondes.
Priorité basse
🌐 Déploiement cloud
Déployer Flask sur Heroku, Railway, ou un VPS. Actuellement SENTINEL ne tourne qu'en local. Un déploiement cloud permettrait un accès depuis n'importe où.
Priorité basse
🎯 Seuils configurables
Permettre à l'admin de modifier les seuils P5/P10 (-0.099 / -0.027) depuis l'interface. Actuellement codés en dur dans app.py et dans le HTML.

Glossaire
Définitions des termes techniques utilisés dans ce document
TermeDéfinition simple
IoT"Internet of Things" — objets connectés (capteurs, caméras, thermomètres) qui envoient des données en permanence
Isolation ForestAlgorithme qui détecte les valeurs anormales en construisant des arbres de décision aléatoires. Plus facile à isoler = plus anormal
Anomaly ScoreNote entre -1 et +0.5 donnée par l'algorithme. Négatif fort = anomalie grave. Proche de 0 = normal
InfluxDBBase de données spécialisée pour les données horodatées (températures, prix, mesures IoT). Beaucoup plus rapide que SQL pour ce type de données
FluxLangage de requête d'InfluxDB. Comme SQL mais conçu pour les séries temporelles
FlaskMini-framework Python pour créer des sites web et des API. Simple mais puissant
API RESTInterface qui permet à un programme (le navigateur) de demander des données à un serveur via des URL. Ex: /api/data retourne les KPIs en JSON
SPA"Single Page Application" — l'interface ne recharge jamais la page, elle met à jour dynamiquement le contenu via JavaScript
RBAC"Role-Based Access Control" — système de permissions selon le rôle (admin, opérateur, citoyen)
SIL 1Niveau d'intégrité de sécurité 1 (IEC 61511) — exige un recall ≥ 90% pour les systèmes de sécurité industriels
RecallTaux de détection : sur 100 vraies anomalies, combien le système en a détecté ? Un recall de 97% = 97 détectées, 3 manquées
TSM / IOxDeux moteurs de stockage différents dans InfluxDB Cloud. TSM pour l'API Flux, IOx pour SQL. Les données ne se voient pas entre les deux
Raspberry PiMini-ordinateur utilisé pour rejouer le dataset et l'envoyer à InfluxDB Cloud
ESP32Microcontrôleur WiFi/Bluetooth pour les capteurs IoT. Serait utilisé dans une installation réelle
bcryptAlgorithme de hachage des mots de passe. Transforme "junior2" en une chaîne illisible stockée en base
LPGGaz de pétrole liquéfié (butane + propane) — détecté par les capteurs
COMonoxyde de carbone — gaz dangereux produit par la combustion incomplète
TVOCComposés organiques volatils totaux — indicateur de polluants chimiques dans l'air
